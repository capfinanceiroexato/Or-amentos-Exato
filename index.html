🏆 Como funciona a classificação de clientes?

Cada cliente recebe uma categoria — Ouro, Prata ou Bronze — de acordo com o valor estratégico que representa para a empresa. A categoria define a prioridade de atendimento: quem é Ouro aparece em destaque em todas as telas, nos relatórios em PDF e no diagnóstico da C@p Consultoria.

🥇
Cliente Ouro
Alta prioridade

São os clientes mais estratégicos e valiosos para a empresa.

  • Possuem vários equipamentos ou unidades.
  • Contratam projetos de maior valor.
  • Mantêm contratos de manutenção ou suporte recorrente.
  • Compram novos sistemas com frequência.
  • Têm potencial para indicar novos clientes.
💡 ExemploUma indústria com câmeras, controle de acesso por reconhecimento facial, manutenção mensal e projetos de expansão.
🥈
Cliente Prata
Potencial de crescimento

São clientes que compram regularmente ou possuem uma estrutura intermediária.

  • Contratam instalações de médio porte.
  • Possuem alguns equipamentos instalados.
  • Podem contratar manutenção eventualmente.
  • Têm possibilidade de ampliar os sistemas existentes.
💡 ExemploUm supermercado com câmeras e alarme, que pode futuramente instalar controle de acesso e leitores faciais.
🥉
Cliente Bronze
Atendimento padrão

São clientes com menor volume de compras ou relacionamento comercial pontual.

  • Contratam serviços pequenos ou isolados.
  • Possuem poucos equipamentos.
  • Não têm contrato recorrente de manutenção.
  • Compram principalmente quando surge uma necessidade.
💡 ExemploUm pequeno comércio que contrata a instalação de quatro câmeras e não possui outros serviços contratados.

Segurança dos dados

💾 Backup dos Dados

Baixe uma cópia completa de orçamentos, clientes, produtos e cadastros. Guarde o arquivo em local seguro (Google Drive, OneDrive, pen drive). O arquivo .json serve para restaurar o sistema; a planilha .xlsx é para consulta no Excel.

⬇️ Fazer backup agora
Baixa a versão mais recente direto do servidor.
♻️ Restaurar de um arquivo
Selecione um arquivo .json de backup. Antes de restaurar, o sistema baixa automaticamente um backup do estado atual.
📁 Backup automático em uma pasta do computador
O sistema salva sozinho uma cópia na pasta escolhida, no período definido. Funciona no Google Chrome ou Microsoft Edge, enquanto o sistema estiver aberto neste computador.
Este navegador não permite salvar em pasta. Abra o sistema no Google Chrome ou Microsoft Edge (computador).

O que é um orçamento "Não Selecionado"?

O cliente optou por outra opção — o orçamento não foi reprovado. Tivemos a venda de outro serviço para esse cliente, por isso esta proposta específica não foi escolhida.

❌ Reprovado = cliente não fechou nada (perda) 🔀 Não selecionado = cliente fechou outro serviço conosco
